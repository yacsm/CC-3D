# 《钢铁侠 3》里的人机交互与可视化融合：头脑风暴

> 目标：从《钢铁侠 3》(Iron Man 3, 2013) 中梳理"人机交互 + 可视化融合"的想象，提炼出可复用的设计原则，再用 three.js / WebGL 做可运行的概念原型。
> 说明：本项目只借用电影里的**交互理念**，所有模型、界面和数据都是程序化生成的原创内容，不复刻电影的美术素材。

## 二、提炼的设计原则

1. **空间即界面**：信息不在矩形屏幕里，而是放在它所描述的东西所在的空间位置（零件在身体旁，热源在爆心）。
2. **具身交互**：用手直接抓、拉、甩；用身体"走进"数据。操作动词和物理世界一致，学习成本低。
3. **多源融合于同一坐标系**：点云、录像视锥、热力图、时间轴共享一个 3D 坐标与一条时间线，关联关系一目了然。
4. **时间是一个可以拖动的维度**：现场可以"倒带"，同一空间里看到前后因果。
5. **AI 是协作者而非工具**：语音解说当前看到什么、下一步建议做什么；把推理链（逐跳追踪、反向弹道）画出来，人可以审查。
6. **从概览到细节的连续缩放**：地球 → 城市；大脑外部 → 内部；整机 → 零件，没有页面跳转。
7. **注意力引导**：锁定框、扫描线、脉冲环把视线引向关键证据；颜色语义固定（青=正常数据，橙=关注，红=告警/结论）。

## 三、技术映射（three.js / WebGL）

| 想象 | 实现手法 |
|------|----------|
| 全息质感 | 自定义 `ShaderMaterial`：菲涅尔边缘光 + 世界坐标扫描线 + 加法混合，`UnrealBloomPass` 泛光 |
| 爆炸视图 | 每个零件记录"原位 / 展开位"，按展开系数插值；射线拾取 + 视线平面拖拽；越过回收圈即抛物线飞出淡出 |
| 现场点云 | 在程序化建筑表面按面积采样 1.5 万点；顶点着色器里按"到爆心距离 / 冲击波到达时间"计算位移和受热颜色，时间轴只改一个 uniform |
| 热力图 | 地面片元着色器：高斯热斑随时间扩散并缓慢衰减，叠加等距环 |
| 监控融合 | `CameraHelper` 画出监控机位视锥，可一键切换到该机位视角 |
| 反向弹道 | 碎片终点 → 爆心的线段集合，揭示单一点源 |
| 神经脉冲 | 2.6 万点的脑形点云 + 1800 条分段连线；片元着色器沿线参数 `aT` 推进脉冲头 |
| 注入波前 | 以脑干为原点的距离场，`uWave` 推进时着色从青变橙 |
| 信号弧线 | 球面坐标 → 二次贝塞尔弧，`setDrawRange` 逐步绘制；节点用面向球外的环做脉冲 |
| HUD | 独立 2D Canvas 叠加层，把 3D 目标投影到屏幕画锁定框，头盔模式加地平线/罗盘/仪表 |
| 手势 | MediaPipe Hand Landmarker：食指=光标，捏合=按下/拖动，双手捏合张开=展开/缩放（与鼠标走同一套输入接口） |
| 3D 标签 | `CSS2DRenderer`，DOM 标签可点击触发相机飞行 |

## 四、多视图联动：把"协同多视图"搬到空中（场景 5）

电影里的全息工作台从来不是一块屏幕，而是**一圈围绕着人和物体的视图**：现场模型在中间，录像、温度、身份资料悬浮在旁边，主角指向任何一处，相关信息就在其他地方亮起来。这正是可视化领域的 *Coordinated Multiple Views*（协同多视图）思想，只是把它从二维窗口搬进了三维空间。

| 视图 | 数据源 | 可做的交互 | 联动效果 |
|------|--------|------------|----------|
| 中心 3D 现场 | 点云 + 人员轨迹 | 点人物选中 | 所有视图同时高亮此人 |
| 监控 CCTV-07 | 另一台相机的**实时渲染画面** + AI 检测框 | 点检测框 | 同上；面板与真实机位之间有虚线"来源线" |
| 俯视态势 | 正交航拍渲染 + 轨迹 + 监控视野扇形 | **拖拽框选区域** | 框内的人在所有视图中被选中 |
| 体温时间曲线 | 热成像（对数坐标） | 拖动 = 全局时间轴；点曲线选人 | 时间变化传到每个视图 |
| 距离 × 峰值体温 | 融合分析 | **拖拽刷选**；点选 | 离群点 X27 一眼可见 |
| 人员档案 | 身份 + 基站 + 监控可见性 | 点行选中 | 左侧检查器显示融合档案 |

关键设计：

- **数据飞线**：同一个人在 5 个视图里各有一个"分身"（检测框、地图点、曲线、散点、表格行），选中后用流动的橙色曲线把 3D 人物和这些分身连起来，联动关系从"颜色同步"变成看得见的空间连接；悬停用白色线做预览。
- **空间中的视图管理**：视图自动绕竖直轴朝向观察者；拖动标题栏可以把视图放到空中任意位置；点 ▢ 让相机飞到该视图正前方；底部投影光束标示悬浮位置。
- **同一时间轴**：所有视图共享全局时间 T，体温曲线本身就是时间滑块。
- **推理线索**：只看任意单一数据源都发现不了问题；把轨迹（一直站在爆心）、热成像（爆炸前 6 秒指数升温）、通信（没有手机信号）三者叠在一起，嫌疑人才浮现出来。"找出异常"按钮会直接演示这一点。

## 五、下一步可以继续发散的方向

- **语音输入**：Web Speech API，"把胸甲放大"、"倒回爆炸前两秒"。
- **WebXR**：把四个场景放进 VR/AR 头显，真正"走进"现场与大脑。
- **真实数据**：现场换成 LiDAR/摄影测量点云（`.ply`/`.las`）；大脑换成 MRI 体数据做体渲染（ray marching）；地球用真实 GeoJSON 与 traceroute 结果。
- **双手直接操纵**：用双手关键点直接定义旋转轴和缩放（类似 VR 中的双手抓取）。
- **协同**：多人同时操作同一全息场景（WebRTC / WebSocket 同步状态）。
- **装甲远程驾驶**：用头部朝向 + 手势控制远处的机器人模型，第一人称 HUD 回传。
