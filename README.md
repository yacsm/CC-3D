# HOLO·LAB：全息交互实验室

受《钢铁侠 3》启发的**人机交互 / 可视化融合**概念原型，基于 three.js + WebGL。

研究与设计思路见 [`docs/brainstorm.md`](docs/brainstorm.md)。

## 四个场景

| 场景 | 体验 |
|------|------|
| 1·装甲工作台 | 全息装甲爆炸视图；拖动零件，扔到橙色圈外即丢弃；"召唤组装"让零件逐件飞回 |
| 2·现场重建 | 1.5 万点的现场点云 + 时间轴倒带 + 地面热力图 + 监控视锥 + 反向弹道追溯 + 可点击的证据标签 |
| 3·全息大脑 | 2.6 万神经元点云与脉冲连线；可隔离单个脑区、触发"注入波前"、飞进大脑内部 |
| 4·信号溯源 | 全息地球，信号在中继站之间逐跳追踪，最后锁定发射点 |
| 5·多视图融合 | 5 个联动视图悬浮在现场上空：监控实时画面、俯视航拍轨迹、体温时间曲线、距离×体温散点、人员档案。悬停 / 点选 / 刷选在所有视图间同步，数据飞线把 3D 人物与各视图中的对应数据连起来；视图可拖动、可聚焦 |

全局功能：

- **H**：头盔 HUD 视角（地平线、罗盘、仪表、锁定框）
- **G**：摄像头手势控制（MediaPipe，需联网和摄像头权限）
  - 食指移动 → 光标；拇指和食指捏合 → 抓取/拖动（捏住空白处拖动 = 旋转视角）
  - 双手同时捏合后拉开/靠拢 → 展开模型 / 缩放
- **1–4**：切换场景；底部字幕条是 AI 管家的语音解说

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建到 dist/
```

## 结构

```
src/
  main.js        渲染器、后处理泛光、统一输入（鼠标/手势）、场景切换
  holo.js        全息材质（菲涅尔 + 扫描线）、工具函数
  hud.js         2D HUD 叠加层（目标投影、头盔模式）
  gesture.js     MediaPipe 手势 → 统一输入事件
  ui.js          面板控件
  panels.js      空中悬浮视图框架（Canvas 内容 + 渲染目标底图 + 射线命中→像素坐标）
  scenes/
    armor.js     装甲工作台
    crime.js     现场重建
    brain.js     全息大脑
    globe.js     信号溯源
    fusion.js    多视图融合（联动视图 + 数据飞线 + 多源数据模拟）
```

所有模型均为程序化生成，不包含电影素材。
